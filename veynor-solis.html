Hardware

Ours. Down to the board.

Built around the Rockchip RK3588 — eight cores and an onboard NPU, silicon usually reserved for flagship tablets, not phones. We didn't license a reference design and skin it. We drew our own schematic, laid out our own carrier board, and built the handset PCB from a blank sheet.

Software

Android underneath. Nothing like it on top.

Veynor Solis runs on Android — the apps, the ecosystem, the compatibility you already rely on. But the interface is entirely ours: a custom UI, built from scratch, every screen and gesture designed in-house. Same foundation everyone trusts. Nothing off the shelf on top of it.

Longevity

Buy it once. Upgrade it forever.

The board is modular by design. A new revision drops in, the shell stays — upgradable at any time, for as long as we keep building. Veynor Solis is built to outlast the spec sheet it shipped with.
